## Проверки

Локально: **268 passed**, 0 failures, 0 skips; предупреждение Starlette об
устаревающем интерфейсе httpx TestClient не влияет на результат.
Тесты включают алгоритмы, production-защиту, C++ протокол Arduino и JS safety.

`python tools/check_production.py --stress` проверил настоящий Uvicorn по HTTP:
главную, JS/CSS/Serial, `/api/project`, healthcheck, референсные результаты,
сравнение FIXED/V2, ручной поток, пешеходов и отказ чужому Origin/лаборатории
без ключа. Одновременно удерживались 8 сессий по 4 контроллера, длительность
генерации 600 с, поток 25 авто/мин на каждый подход, по 960 ручных машин;
лаборатория завершила 56 запусков. Завершение сервера штатное.

Пик памяти локального процесса: **75 680 КиБ (73,9 МиБ)**, максимум 3 потока.
Это измерение конкретного сценария, без локального cgroup-ограничения.
Оно не гарантирует работу при любой нагрузке или на CPU провайдера.
Docker/Podman локально отсутствуют; результат контейнерной проверки будет в
[GitHub Actions](https://github.com/durovp/AdaptiveTraffic/actions).

Научные алгоритмы, параметры и `web/data/reference_results.json` сохранены.
Четыре физических автомобильных светофора, пешеходный сигнал и кнопка,
Web Serial и аварийный режим сохранены. Предыдущий этап проверил браузер с
реальным C++ ядром прошивки и компиляцию Uno; это не испытание реальной платы.
USB обслуживает браузер пользователя, сервер не открывает `/dev/tty*`.

## Оставшийся шаг

В своём терминале выполнить `/tmp/adaptive-amvera-cli/amvera login` и ввести
учётные данные там. Сообщить агенту, что вход выполнен, и название уже оплаченного
проекта, если он есть. Пароли и токены не отправлять в чат. Альтернатива через
MCP описана в [инструкции](DEPLOY_AMVERA_RU.md#доступ-для-следующего-запуска-codex).

После доступа: проверить существующее приложение и оплату, настроить Host/Origin
и секрет лаборатории, проверить права UID 10001 на `/data/results`, выполнить
deploy, проверить build/run logs, сертификат и публичные HTTPS API. Только затем
записать фактический URL и считать публикацию завершённой. Проект/тариф пока
не выбраны, круглосуточная работа не подтверждена. «Начальный» (500 МБ, 0,25 CPU,
около 290 ₽/30 дней по документации) — кандидат, а не заказ услуги.

Обновления: обычный push в существующую `main`; автодеплой требует отдельно
подключённой GitHub-интеграции Amvera. Webhook пока не настроен из-за отсутствия
доступа. Секреты вводятся в панели Amvera, не в исходниках.

Локальный резервный режим: `python main.py --web --no-browser`, затем
`http://127.0.0.1:8000`. После установки зависимостей интернет для этой работы
не нужен. Исследования и CSV не удалялись; временные результаты проверки
остаются в исключённой из Git папке `results/amvera_verification/`.
