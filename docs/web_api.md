# Веб-интерфейс: локальный и production

Backend: `adaptive_traffic/web.py`, frontend: `web/index.html`, `web/static/`.
Запуск: `python main.py --web [--web-port 8080] [--no-browser]`.
Все страницы и ресурсы отдаются с одного origin; локальная команда слушает loopback.
JSON-спецификация API: `/openapi.json`. Swagger/ReDoc отключены, поскольку их
стандартная страница использует CDN.

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/project` | Контроллеры, параметры по умолчанию, разрешённые настройки |
| GET | `/api/scenarios` | Сценарии и русские объяснения |
| GET | `/api/reference-results` | Зафиксированные данные настоящего holdout |
| POST | `/api/sessions` | Создать сессию |
| GET | `/api/sessions/{id}` | Состояния и метрики |
| DELETE | `/api/sessions/{id}` | Освободить сессию |
| POST | `/api/sessions/{id}/advance` | Выполнить `steps` шагов (1–1000) |
| POST | `/api/sessions/{id}/restart` | Очистить очереди/события, сохранить план; можно сменить controllers |
| POST | `/api/sessions/{id}/pedestrian` | Ручной запрос всем сравниваемым контроллерам |
| POST | `/api/sessions/{id}/inject` | Добавить `count` машин каждому из `directions` |
| POST | `/api/sessions/{id}/finish` | Выполнить оставшиеся шаги и получить итоги |
| GET | `/api/sessions/{id}/export` | JSON завершённой симуляции с параметрами и событиями |
| POST | `/api/comparison` | 2–4 контроллера; необязательный source_id для повторения событий |
| POST | `/api/experiments` | Фоновая headless-серия |
| GET | `/api/experiments/{id}` | Прогресс, статус, сводка и пути скачивания |
| GET | `/api/experiments/{id}/files/{name}` | Только results.csv, diagnostics.csv, metadata.json |

Пример тела создания сессии:

```json
{"scenario":"NS_HEAVY","controllers":["ADAPTIVE_V2"],"seed":42,
 "duration":180,"interactive":true,"pedestrian_times":[],"settings":{}}
```

CUSTOM: `scenario: "CUSTOM"`, `custom_rates: [12,12,4,4]` (N/S/E/W, авто/мин).
`duration` 10–3600 с; seed 0–2147483647. Для лаборатории дополнительно `runs`
1–50, `scenario: "ALL"` для 7 сценариев, `interactive` всегда false.
Настройки только из списка `/api/project/settings`; неверные значения получают
422 с описанием. Истёкшая сессия — 404; переполнение — 429; занятая лаборатория — 409.

## Одна модель

Обычная Simulation не принимает ручной ввод (`allow_injection=False`). Веб явно
включает его только для interactive sessions. При injection сначала поступают
плановые автомобили с arrival_time <= time, затем новые ручные: FIFO сохраняется.
TrafficPlan неизменяем; ручные Vehicle имеют отдельные уникальные ID, не заменяют
будущие приезды и участвуют в общих метриках обслуженных автомобилей.

В сравнении все Simulation получают **тот же объект** TrafficPlan и расписание
пешеходов. Сессия выполняет шаги синхронно. Ручное событие содержит model time,
тип, направления и количество, применяется всем контроллерам под блокировкой.
Пешеходная кнопка означает одинаковые попытки подачи запроса: каждый автомат
сам объединяет повторы, если его предыдущий цикл ещё не закончился.

`source_id` создаёт сравнение на исходном плане и повторяет журнал ручных событий
до исходного времени. Ни очередь, ни результаты одного алгоритма не копируются
другому. Restart сбрасывает события. После конца генерации ручные события
запрещены: различные времена drain не должны создавать различные входы.

Веб использует общие `get_view_state`, `calculate_metrics`, `calculate_diagnostics`,
`run_experiments`, `summarize` и `compare_all_pairs`. Canvas не обслуживает автомобили
и не принимает решения. Веб и pygame рисуют разрешённые Python события проезда.
Живые метрики частичны, итоговый флаг завершения обязателен для сравнения.

## Хранение и локальная безопасность

Не более 32 сессий с TTL 30 минут; cleanup при доступе и каждые 30 секунд.
Мутации каждой сессии сериализованы RLock. Лаборатория имеет один worker и
принимает одну активную задачу. История задач в памяти ограничена 16 записями
и 2 часами для завершённых, результаты на диске не удаляются.

Названия файлов заданы перечислением, папку выбирает сервер с timestamp и UUID.
API не принимает файловые пути, не выполняет shell, не открывает файловый менеджер.
Проверяются Host и Origin. Нет CORS-разрешения внешним сайтам, cookies, аналитики,
БД и регистрации. В локальном режиме лаборатория открыта; в production
требуется секрет ADMIN_TOKEN.

Зависимости требуют интернета только при первоначальной установке. Сайт не
выполняет внешних сетевых запросов; внешний GitHub — обычная ссылка пользователя.

## Smoke-проверка

Автоматические API-тесты: `pytest tests/test_web.py -q`.
Проверка человеком: главная → «Попробовать самим» → «Пробка NS» → пешеход →
«Сравнить с FIXED» → «До конца» → таблица и JSON. Лаборатория: 10 seeds,
выбранные контроллеры → прогресс → CSV, diagnostics и графики.
Проверить также CUSTOM, четыре алгоритма, смену контроллера, паузу, ×100,
перезапуск, стенд и ошибку MIN_GREEN > MAX_GREEN.

## V3: аппаратный вывод и публичный режим

`/api/project` содержит hardware (версия, скорость, интервалы) и hosting
(режим, лимит длительности, требуется ли ключ лаборатории). GET `/healthz`
возвращает status=ok. Снимок сессии содержит монотонную revision: reset, advance
и ручное событие увеличивают её. Для физического режима advance передаёт
`{"steps":1,"expected_revision":предыдущая_revision}`; несовпадение возвращает
409 до изменения модели. Контроллеры, Config и TrafficLight не изменены.

Serial находится только в браузере, сервер не открывает USB. Используется
существующий get_view_state(). Проверяются свежесть HTTP (не более 1500 мс),
порядок revision, время и ACK. Каждый следующий аппаратный шаг начинается
не ранее 1010 мс после предыдущего подтверждения; небольшое отставание от
идеальной ×1 допустимо, ускорение не догоняет пропущенные интервалы.

Production берёт ALLOWED_HOSTS, ALLOWED_ORIGINS и ADMIN_TOKEN из среды;
настройки и точные лимиты описаны в DEPLOY_AMVERA_RU.md. Все POST требуют
разрешённый Origin; только POST /api/experiments дополнительно требует
`Authorization: Bearer <ADMIN_TOKEN>`. Секрет не передаётся в query string.
Идентификаторы сессий/задач — случайные UUID, служат непредсказуемыми ссылками
доступа; отдельной регистрации и списка чужих сессий нет. Не распространяйте
ID приватной демонстрации. CORS не открыт, CSP ограничивает скрипты self,
Permissions-Policy разрешает serial только этому origin. Лимиты памяти/CPU
задаются контейнером/тарифом, дополнительно к ограничениям API.
